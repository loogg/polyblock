# PolyBlock GUI 回归验收清单（Mandatory Pre-Release Checklist）

每次修改布局、样式、画布交互、弹层/下拉框、积木定义或内置演示项目后，在交付前必须按以下验收项逐项完成真实浏览器验证与截图目视审查：

## 1. 层级与浮层遮挡验收（Z-Index Stacking）
- [ ] **顶栏项目下拉框（`.project-dropdown-menu`）**：打开后完整浮于 `.script-tab-bar`、Blockly 飞出栏与积木画布之上，第一项、分割线与底部按钮零遮挡、可正常点击。
- [ ] **脚本栏句柄切换下拉框（`.handle-dropdown-menu`）**：打开后完整浮于 Blockly 飞出栏与积木画布之上，零遮挡。
- [ ] **Blockly 下拉菜单（通道下拉 / 颜色下拉 / 右键菜单）**：在浅色与深色主题下清晰可读，不被工具栏或侧栏裁切。
- [ ] **模态弹窗（项目配置 / 通道别名）与 Toast**：始终位于全部层级最上方（`z-index: 150~180`），ESC 与点击遮罩可关闭。

## 2. 画布缩放与飞出栏几何验收（Zoom `50%` / `92%` / `150%`）
- [ ] **搜索框随飞出栏动态适配**：在 `50%`、`60%`、`92%`、`150%` 缩放下，`.flyout-search-dock` 右边界严格位于飞出栏边界内（`searchRect.right <= flyoutRect.right`），**不溢出到网格画布上**。
- [ ] **飞出栏标题零遮挡**：任意缩放比例下，飞出栏顶部第一个分类标题/按钮位于搜索框下边界下方（`firstItem.top >= searchRect.bottom`）。
- [ ] **「整理」与「居中」按钮**：画布工具条点击「整理」可将任意凌乱/重叠的顶层积木重新排布为无重叠整齐列布局。

## 3. 内置演示项目画布零重叠与双语健康度验收
- [ ] **零重叠包围盒校验**：打开 L1~L4 所有内置演示项目的每一个句柄与脚本，任意两个顶层积木块的 SVG `getBoundingClientRect()` 交叠面积为 **0**。
- [ ] **双语 0 诊断**：L1~L4 全部脚本在 Lua 5.4 与 Python 3 下均生成干净代码且诊断数 `diagnostics.length === 0`。
- [ ] **多包模拟面板无裁剪**：右侧「模拟」面板展开 2~3 张外设卡片时（如 L4 旗舰项目），每张卡片 `flex-shrink: 0`，头部、进度条、滑块、开关与下方 RT 监控卡全部完整可滚动无纵向挤压裁剪。

## 4. 积木交互与外设真实语义验收
- [ ] **单块抽出与整段拖拽**：普通拖拽语句块按 Blockly 默认带动下方连接块；按住 `Ctrl`/`Alt` 拖拽或右键「仅抽出此积木（自动缝合上下）」可只抽单块并自动接回上下积木。
- [ ] **外设语义准确**：板载三色灯（`tricolor`）严格限定 红/绿/蓝 + 关闭，不与全彩灯（`rgb`）混淆。
- [ ] **运行期零报错**：深色与浅色主题下全流程 `ConsoleErrors === 0` 且日志控制台 `ERR === 0`。

## 5. 协程调度与事件公平性验收（Scheme A 对齐实板）
- [ ] **全局 `sleep_ms` 导出**：Lua 导出「等待 ms」生成全局 `sleep_ms(ms)`（无 `os.clock()` 忙等），定时器与周期控制保留在 `rt.*`。
- [ ] **正常速度多路定时不饿死**：在「正常（180ms）」可视化步进速度下运行「事件回调与多路定时器示例」（`board_vm`：`main.lua` + `timers.lua`），`on_run`、`T0` 以及按键触发的 `T1` 均能正常触发且不互相饿死；点击「停止」能优雅执行 `on_stop`。
- [ ] **选项 A 严格检查与设置项**：事件回调内拖入「等待 ms」在诊断栏标红报错；设置页 `on_start 协程时间片` 与 `单次事件回调 / 阻塞超时保护` 显示清晰且生效。
