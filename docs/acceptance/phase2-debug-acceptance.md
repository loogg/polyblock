## 2. 本轮审查闭环修复记录
1. **变量标识映射修复**：在 `LuaBackendAdapter` / `PythonBackendAdapter` 收集变量名映射前先调用 `generator.init(workspace)`，彻底消除 Blockly `nameDB_` 弃用警告并确保 Python 保留字变量（如 `sum` → `sum2`）正确映射回原中文/英文名显示。
2. **SourceMap 单行精确度修复**：改为按每行最内层归属块（`ownerId`）更新 `sourceMap`，消除 Blockly `STATEMENT_SUFFIX` 晚于 `scrub_` 导致的同级链表多行连带高亮问题。
3. **检查器页签紧凑对齐**：优化 `.pane-tab` 不可换行及断点角标（`● 1` / `✓`），确保 1440×900 下有断点时页签与「清断点」按钮严格单行展示。
